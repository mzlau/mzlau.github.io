A hardware platform for testing multi-agent control algorithms on real wheeled robots, built for my Ph.D. work in the Dynamic Systems and Control Laboratory at Arizona State University.

- Autonomous robots on Raspberry Pi and Arduino, with V2V and V2X communication for real-time data exchange.
- A physics-based, high-fidelity simulator of the robot in SimScape Mechanical, used to check controllers before running them on hardware.
- Used to validate flocking and collision-recovery controllers, including safe reinforcement learning designs.
